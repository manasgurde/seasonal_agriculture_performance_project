# Seasonal Agriculture Performance Analysis

Major Project for VOIS AICTE Batch 1 (2026-2027).

## Description
This project analyzes agricultural performance data across different seasons (Kharif, Rabi, and Zaid). It covers data exploration, cleaning, seasonal comparisons (yield, production, profit, resource usage), statistical testing, and data-driven recommendations.

## Files in this Repository
- `Seasonal_Agriculture_Performance_Analysis.ipynb`: Main Jupyter Notebook containing the full analysis and visualizations.
- `seasonal_agriculture_performance_dataset.csv`: Dataset containing 4,001 agricultural records.
- `Major Project_Seasonal Agriculture Performance Analysis..pdf`: Official project problem statement.

## Requirements
```bash
pip install pandas numpy matplotlib seaborn scipy
```

## How to Run
Open the notebook using Jupyter Notebook or VS Code and run all cells:
```bash
jupyter notebook Seasonal_Agriculture_Performance_Analysis.ipynb
```
